## 1. 摘要

《左腳踩右腳：永動機研究所》是一款以「數值互相抬升」為核心機制的十關配點解謎遊戲。玩家扮演永動機研究所新進工程師，將有限零件分配給串聯成閉環的多台裝置，使整圈倍率乘積大於 `1.000`，形成自行成長的正回饋循環。

## 2. 目標玩家

- 使用桌上型或行動裝置瀏覽器的休閒與邏輯解謎玩家。
- 想在免安裝、無失敗懲罰的環境下體驗「資源配點與正回饋閉環」機制的玩家。

## 3. 目標與成功標準

| 目標 | 成功標準 |
|---|---|
| 完整十關唯一解體驗 | 10 個主題關卡（3～8 台裝置）皆具唯一正解，通關順序逐步解鎖 |
| 即時回饋與無障礙操作 | 配點調整與啟動模擬皆在瀏覽器端即時演算，支援窄螢幕（320px）無水平溢出 |
| 本機存檔與容錯 | 過關紀錄存於瀏覽器 `localStorage`，遇損壞 JSON 時能安全重置不崩潰 |
| 零月費營運 | 公開版純靜態部署於 GitHub Pages，不使用資料庫或後端伺服器 |
| 效能與 CI 驗收 | 通過 `oxlint`、型別檢查、Playwright E2E（含 320px 20 次操作 p95 `< 100ms`）與靜態建置 |

## 4. 範圍

### 4.1 已實作範圍（現況）

- **10 個完整關卡（`app/levels.ts`）**：從「失控鍋爐房」至「宇宙自舉」，每關具非線性倍率階梯（`rates`）、預算零件數與唯一正解。
- **互動模擬介面（`app/page.tsx`）**：上方關卡選擇列、關卡資訊看板、零件托盤、裝置卡片網格（`＋`/`−` 步進器）與終端模擬面板（逐台活化動畫與成敗判定）。
- **本機存檔與平台整合**：透過 `localStorage`（`left-foot-right-foot-completed`）保存進度，頁首連結 Playmint 遊戲入口，並嵌入 Harbor 維護檢查腳本。

### 4.2 明確排除

- 帳號登入、雲端存檔或排行榜。
- 伺服器端演算或 Cloudflare D1 資料庫寫入（`db/schema.ts` 保持空白）。
- 付費資源或第三方追蹤腳本。
