# 左腳踩右腳：永動機研究所

一款以「數值互相抬升」為核心的十關配點解謎遊戲。

你是永動機研究所的新進工程師。你的任務是走進十個風格迥異的世界，把有限資源分配給互相連結的裝置，讓數值跑完一整圈後不減反增。

## 立即遊玩

**[開啟 GitHub Pages 遊戲](https://frobel0520.github.io/left-foot-right-foot/)**

支援桌面與手機瀏覽器，不需要安裝。

## 核心概念

每一關的裝置都會形成一個完整閉環。例如第一關：

```text
電力 → 熱能 → 蒸汽 → 電力
```

每台裝置都有自己的非線性升級曲線。當所有倍率的乘積大於 `1`，資源每繞一圈就會增加，系統也就能「左腳踩右腳」地自行成長。

```text
加熱倍率 × 鍋爐倍率 × 渦輪倍率 > 1
```

## 遊戲方式

1. 將本關提供的強化資源分配給所有裝置。
2. 使用 `＋`、`－` 調整每台裝置的等級。
3. 用完全部零件後，按下「啟動閉環」。
4. 觀察能量依序通過三台裝置。
5. 測試結束後，若核心資源持續成長即可通關並解鎖下一關。

零件可以自由重新分配，失敗不會造成任何懲罰。十關都有不同裝置數、資源數、視覺主題和唯一有效配置；候選配置從第一關的 13 組一路增加到最終關的 98,758 組。

## 本機執行

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

建立 GitHub Pages 靜態版本：

```bash
npm run build:pages
```

輸出檔案會產生在 `pages-dist/`。推送至 `main` 分支後，GitHub Actions 會自動更新公開遊戲。
